# Example: Haus Sonnenhang

A complete set of material for the house-model skill, made up from HouseVis's demo house: no real
building, no real people. It shows what the skill works best with, and you can try the skill or
the in-app assistant on it before you gather your own plans.

| File | What it is |
|---|---|
| `Sonnenhang-Eingabeplanung.pdf` | The architect's plan set: site plan, floor plans, roof plan, two sections, four elevations (German conventions, A3) |
| `plan-wintergarten.pdf` | The conservatory maker's drawing, added later, as real projects have them |
| `room-names.txt` | Which room on the plans is which room in the Miniserver |
| `plan-changes.txt` | What was built differently from the plans |

Put the files into `plans/sonnenhang/` and ask Claude Code to build the house model from them, or
attach them in the app's house assistant. The plans and the notes are in German, as the house's
data is.
